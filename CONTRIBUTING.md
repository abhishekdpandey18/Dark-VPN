# Contributing

Thanks for considering a contribution!

1. Fork the repository and create a focused branch.
2. Keep changes compatible with Python 3.10+ and systemd-based Linux.
3. Do not include VPN profiles, private keys, certificates, credentials, or personal data in commits.
4. Test syntax with `python3 -m py_compile dark_vpn/dark_vpn.py`.
5. Describe the problem, change, and test environment in your pull request.

For larger changes, open an issue first to discuss the approach.
